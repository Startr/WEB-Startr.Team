How It Works: The Framework

The engine behind every Startr.Team agent is open, specified, and small enough to read in an afternoon. Every run writes a markdown audit trail. Plans are notes you can open and edit in Obsidian while your agents work them. Nothing goes out the door unless a person says send.

  • Read: the Agent Framework specification — the loop, the vault, graph plans, gated dispatch.
  • Run: the examples — a hello agent, a herald, and a draft–review loop.
  • Build: startr-team for Python — one YAML file makes it your agent.
from startr_team import Agent, register_tools
from startr_team.tools import todays_date

register_tools(todays_date)
print(Agent().run("Draft a two-line standup note about shipping the vault."))
